# Exceptions for scripts/check_api.py. One entry per line:
#
#   <kind> <identifier> [in=<path glob>] <reason, at least three words>
#
# Kinds:
#   absent    The skills cite this name because it does NOT exist. It must stay absent from
#             @figma/plugin-typings, and every mention must sit on a line (or right below a
#             line) that says so (not, never, no, instead, throws, TypeError, ...).
#             Forms: figma.x (a chain), .member (any receiver), name() (a bare call in inline code).
#   editor    Exists in the typings, but only in another editor (FigJam, Slides, Buzz). The skills
#             mention it on purpose, usually to warn against it in Design files.
#   receiver  An object outside the Plugin API. Its members are not checked.
#   member    A field of a payload outside the Plugin API. Never checked.
#   global    figma.<x> that is not the plugin global.
#
# Keep every reason true. check_api.py prints entries nothing uses so the list stays short.
